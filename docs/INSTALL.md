# Installing Ethical Hacking Roadmap 2026/2027 on Android

1. Download `app-debug.apk` (or `app-release.apk`) from the GitHub Actions run (Artifacts) or the `ci-results` branch.
2. On your phone: Settings > Security (or Apps > Special access) > **Install unknown apps** > allow your browser/Files app.
3. Open the APK and tap **Install**. Requires Android 7.0 (API 24) or newer; phones and tablets supported, portrait and landscape.
4. First launch plays the 3D intro (tap to skip), then onboarding. Everything works offline.
5. Optional: Settings > AI tutor - paste your own free Gemini or Groq API key to enable the online tutor.
6. Optional: allow notifications for daily study reminders (Android 13+ asks for permission).

The debug and release builds can be installed side by side (debug uses the package `com.bernportal.ehr.debug`).
